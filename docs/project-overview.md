# GLOBAL GAP AI 프로젝트 개요

## 1. 프로젝트 이름
GLOBAL GAP AI

## 2. 프로젝트 목적
세계 여러 나라에서 성장하거나 성공한 사업과 웹서비스를 발견하고,
국가별 시장 공백과 사업 이전 가능성을 AI로 분석하여
새로운 사업 기회를 찾을 수 있도록 돕는 서비스입니다.

## 3. 핵심 질문
"어느 나라에서 성공한 사업이 어느 나라에서는 아직 기회가 있는가?"

## 4. 핵심 기능
1. 사용자 아이디어 분석
2. 한국 사업성 점수
3. 글로벌 사업성 점수
4. 국가 간 시장 GAP 분석
5. 해외 경쟁사 조사
6. 현지 경쟁사 조사
7. 시장 수요 분석
8. 수익화 가능성 분석
9. AI 개선 제안
10. 조사 출처 제공

## 5. 향후 확장 기능
1. 전세계 신생 사업 탐색
2. 국가별 기회 시장 자동 탐색
3. 국가 A → 국가 B 사업 이전 가능성 분석
4. 사업계획서 자동 생성
5. 홈페이지 구조 생성
6. MVP 제작 지원
7. 코드 생성
8. 마케팅 콘텐츠 생성

## 6. 핵심 차별화
단순한 AI 아이디어 평가 서비스가 아니라
"국가 간 사업 공백 발견"을 핵심 기능으로 합니다.

## 7. 첫 번째 MVP
사용자가 아이디어를 입력하면 다음 결과를 보여줍니다.

- 아이디어 요약
- 문제와 고객
- 한국 점수
- 글로벌 점수
- 경쟁사
- 시장 기회
- 위험요소
- 개선 제안
- 출처

## 8. 개발 원칙
- 작은 MVP부터 시작
- 실제 사용자 반응을 먼저 확인
- 성공한 기능만 확장
- 불필요한 기능은 제거
- 공식 API와 허용된 데이터 사용
- 경쟁사 소스코드와 콘텐츠를 복제하지 않음
- 개인정보 최소 수집
- 법률 및 특허 위험을 지속적으로 검토

## 9. 사업 목표
1차 목표: 첫 사용자 확보
2차 목표: 첫 유료 사용자 확보
3차 목표: 월 매출 발생
4차 목표: 반복적인 성장
5차 목표: 독립적인 디지털 자산으로 성장
6차 목표: 운영 또는 매각을 통한 자산화

## 10. 개발 방식
왕초보 창업자가 AI의 도움을 받아 단계적으로 개발합니다.

AI:
기획, 조사, 설계, 코드 작성, 오류 수정, 콘텐츠 제작을 담당합니다.

창업자:
계정 생성, 클릭, 실행, 테스트, 확인, 업로드 및 최종 의사결정을 담당합니다.
